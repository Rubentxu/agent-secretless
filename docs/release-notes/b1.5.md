## Summary

`b1.5` pays the pre-existing `cargo fmt` drift on the
"opción A" pendiente list from the B1.1 receipt. The drift
was a `rustfmt` 1.5→1.6+ style preference change for match
arms and method chains. 5 files changed, 30 insertions, 26
deletions (net 4 lines). 0 semantic change.

This is a housekeeping release. It contains no feature
changes, no new tests, no dependency updates. It exists
to bring the tree into rustfmt-clean state so future blocks
don't have to either ignore the drift or do the work
inline.
